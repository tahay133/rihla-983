# Riḥla 983

A pixel-art side-scrolling platformer. An Arab traveller crosses the Islamic world in 983 CE, from Samanid Bukhara through Abbasid Baghdad, Fatimid Cairo and Qayrawan, to Umayyad Córdoba.

Work in progress. The design handoff is in [`docs/handoff.html`](docs/handoff.html).

## Run locally

```bash
python3 -m http.server 8983
```

Then open <http://localhost:8983>.
